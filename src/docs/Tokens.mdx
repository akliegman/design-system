# Tokens

Tokens live in `tokens/` as [Design Tokens Community Group](https://www.designtokens.org/) JSON, in two layers.

- **`primitives.json`** holds raw values: oklch color palettes, the spacing base, radii, the type scale, durations and easings. Primitives never reference other tokens.
- **`semantic.json`** holds roles. Each role names a purpose (`surface-raised`, `fg-muted`, `danger-text`) and aliases a primitive. Every color role has a light value in `$value` and a dark value in `$extensions["com.akliegman.modes"].dark`; the build fails if one is missing.

`pnpm tokens:build` turns both files into `src/styles/tokens.css`. Each semantic color becomes a `light-dark()` value, so a single `color-scheme` change on any element switches its whole subtree. A `@theme inline` block maps roles onto Tailwind, after clearing Tailwind's default palette, so `bg-surface` exists and `bg-blue-500` does not. `pnpm tokens:check` fails CI when the CSS is stale.

## Contrast

Every foreground and background pair that a component renders, measured in this browser from computed styles. `scripts/tokens/tokens.test.ts` computes the same pairs from the token JSON and fails below 4.5:1 for text or 3:1 for control boundaries, meaningful icons and focus rings. Primitives are also checked to sit inside the sRGB gamut, so no browser has to clip them.
